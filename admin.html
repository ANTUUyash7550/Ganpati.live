Admin

For security, the master registration list should remain in your private Google Sheet. GitHub Pages is public and cannot safely hold an admin password or secret.

Recommended admin workflow

  1. Open the private Google Sheet connected to the site.
  2. Search Instagram username or private Visarjan code.
  3. Use the sheet as the authoritative registration list.

The public website only sends new registrations to the Apps Script backend; it never downloads the full list.
